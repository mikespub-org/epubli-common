# Epubli Common Classes Library #

Library of commonly used classes like tools and helpers.

### Installation ###

In your [composer](https://getcomposer.org/).json include the following:

```
#!json
{
    "require": {
        "mikespub/epubli-common": "^1.0"
    }
}
```
Then do:

```
#!shell

$ composer install
```
